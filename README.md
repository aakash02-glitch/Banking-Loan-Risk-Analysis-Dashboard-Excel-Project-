# 🏦 Banking Loan Risk Analysis Dashboard (Excel Project)

## 📌 Project Overview
The Banking Loan Risk Analysis Dashboard is an end-to-end Microsoft Excel analytics project designed to analyze customer loan behavior, repayment trends, credit risk distribution, and financial segmentation.  

This project demonstrates practical business analytics workflow including:
- Data Validation
- Feature Engineering
- Exploratory Data Analysis (EDA)
- Pivot Table Analysis
- Interactive Dashboard Design
- Business Insights & Reporting

The dashboard provides interactive filtering using slicers and helps identify repayment performance, customer risk levels, and lending patterns.

# 📌 Key Business Insights

- Excellent credit customers demonstrated the highest repayment performance.
- Medium-risk customers formed the largest customer segment.
- High-income customers received larger loan approvals.
- Poor credit category customers showed lower repayment behavior.
- Employment status showed moderate impact on credit performance.

---

# 💡 Business Recommendations

- Increase approval focus on high-credit customers.
- Apply stricter monitoring for medium-risk borrowers.
- Use income and credit segmentation for smarter lending decisions.
- Expand dashboard automation for real-time analytics.
